LQD Da Nang - Detail v2 Minecraft reconstruction
Supplementary Java reference export: Minecraft Java Edition 1.20.4, DataVersion 3700.
The mobile deliverable targets Minecraft Bedrock. This supplementary Java world does not import directly on mobile.
Java import: copy the LQD_DaNang_Detail_v2_Java_1_20_4 folder into the saves directory of a Java 1.20.4 profile, then open Singleplayer.
Spawn: x65 y65 z219; Creative, peaceful, daylight and weather frozen.
No mods are required for this world. A compatible WorldEdit/Sponge loader is needed only to import .schem files.

Raw detail patches and old component schematics are intentionally excluded: they do not describe the complete Detail v2 map.
